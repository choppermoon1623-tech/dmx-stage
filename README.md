# DMX ステージコントローラ

USB-DMXトランスミッター（Open DMX 互換・FTDI）で、パーライト4台とダービーライト1台を操作するWebアプリです。

- 演出パッド：ボタンかキーを押すだけで「右から左へ」「虹が流れる」「パトカー」など12種類の光り方
- シーンの保存と、キュー（プログラム）の再生。Enter で次へ進む
- 操作画面と設定画面を分けてあり、設定を閉じている間はキーボードで操作できる（? でキー一覧）

## 初期のアドレス

| ライト | 本体のアドレス | 使うch |
|---|---|---|
| パー1〜4 | A001 / A011 / A021 / A031 | 各7ch |
| ダービー | A041 | 6ch（よくある並びの例。実機に合わせて設定で直す） |

※ Web Serial を使うため、Chrome / Edge で動きます。設定・シーンは使っているブラウザに保存されます（「設定を書き出す」でファイルに残せます）。
